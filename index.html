The efficient plan

Phase 0 — 5-minute freebies

First session. qunyx.: steak + upgraded room. Both: catch a fish, change room once, first arena quest.

Phase 1 — Finish the Iceborne story

MR4 → MR5 → Shara → Guiding Lands → Ruiner Nergigante. Take turns hosting.

Phase 2 — The stacking grind

Guiding Lands + tempered / elder / variant investigations together. Capture when you can. Share good investigations.

Phase 3 — Collectibles in chill batches

Rare endemic life, treasures (one locale per session), Lynian photos.

Phase 4 — Arena + gear filler

Arena 50 in small batches. Craft R12 gear as you go.

Phase 5 — Crowns + MR200 LAST

Crown-sniping only after Phases 1–2. Base crowns first, then True crowns.

Crown tracker — the 28 base-game crown monsters

Mini + gold large for each — one shared tick, since you hunt together. Steam can't track crowns, so tick these yourself.

True crowns: Iceborne monsters + Deviljho / Lunastra. No crown for Shara.
